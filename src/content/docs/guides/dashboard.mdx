The dashboard at [tinyfat.com/dashboard](https://tinyfat.com/dashboard) is your control center for managing your agent.

## Overview

The dashboard shows:
- **Job history** — All email interactions
- **Settings** — Allowed senders, API keys (optional)
- **Usage** — Token counts and costs

## Job history

Every email interaction is logged:

| Column | Description |
|--------|-------------|
| **Time** | When the job ran |
| **From** | Sender email address |
| **Subject** | Email subject line |
| **Status** | `complete`, `failed`, or `pending` |
| **Tokens** | Input/output token counts |
| **Cost** | Estimated cost for this turn |

Click a job to see details:
- Full email content
- Agent response
- Error messages (if failed)
- Session hash for `/resume`

## Settings

### Allowed Senders

Control who can email your agent:

- **Exact match:** `alice@example.com`
- **Domain wildcard:** `@company.com` (anyone at that domain)

Your signup email is automatically added.

<Aside type="caution">
  Be careful with domain wildcards. `@gmail.com` would allow any Gmail user to email your agent.
</Aside>

### API Keys (Optional)

By default, your agent uses TinyFat's managed API access with your $1 free credits (or metered usage on Tiny tier).

**Bring Your Own Key (BYOK):** If you prefer to use your own Anthropic API key:

<Steps>
1. Get your key from [console.anthropic.com](https://console.anthropic.com/)
2. Paste it in the API Keys field
3. Click **Save**
</Steps>

With BYOK, you pay Anthropic directly at their rates. A small platform fee may apply to cover email infrastructure costs (pricing TBD).

<Aside type="note">
  Your API key is encrypted before storage. We never see it in plain text.
</Aside>

### Integrations (Tiny tier)

Connect external services:

- **Slack** — Bot token for Slack integration

## Usage tracking

See your agent's resource usage:

- **Credits remaining** — Free tier balance
- **This month** — Total tokens and cost (Tiny tier)
- **Per job** — Breakdown in job history
- **Model** — Which model each job used

## Agent information

View your agent's details:

- **Email address** — Where to send messages
- **Created** — When the agent was provisioned
- **Plan** — Free, Tiny, or BYOK

## Common tasks

### Check why a job failed

1. Open job history
2. Find the failed job (red status)
3. Click to expand
4. Check the error message

Common errors:
- "Out of credits" — Upgrade to Tiny or add BYOK
- "Sender not allowed" — Add sender to allowed list
- "Timeout" — Request took too long, try simpler task

### Add allowed senders

1. Go to Settings → Allowed Senders
2. Enter email address or `@domain.com`
3. Click Add

### View agent response

1. Find the job in history
2. Click to expand
3. See "Response" section
