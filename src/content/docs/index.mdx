## How it works

1. **You email your agent** — Send to `yourname@tinyfat.com`
2. **Agent wakes up** — Container starts with your storage mounted
3. **Agent thinks** — Reads your email, uses tools, reasons
4. **Agent responds** — Writes a reply to its outbox
5. **You get the email** — Response arrives in seconds

Each email triggers one agent "turn" — the agent processes, acts, and responds.

## What can your agent do?

- **Answer questions** using Claude's knowledge
- **Browse the web** with Brave Search  
- **Read and write files** in persistent storage
- **Run shell commands** (git, curl, jq, etc.)
- **Generate PDFs** with Python
- **Remember context** across conversations
- **Send emails** to anyone
