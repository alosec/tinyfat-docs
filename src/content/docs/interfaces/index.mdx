## Comparison

| Feature | Email | Slack | Web App |
|---------|-------|-------|---------|
| Setup | None | Slack app | None |
| Response | 30-60s cold | Real-time | Streaming |
| Mobile | Native | Slack app | Browser |
| Team access | Forward emails | Channel visibility | Just you |
| File browser | No | No | Yes |
| Activity drawer | No | No | Yes |

## Which to use?

- **Email** — Fire and forget. Async tasks. Mobile-first.
- **Slack** — Team visibility. Real-time. Quick questions.
- **Web App** — Active development. Debugging. File editing.

All three share the same agent memory. Switch between them freely.
