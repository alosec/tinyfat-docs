The dashboard at [tinyfat.com/dashboard](https://tinyfat.com/dashboard) includes a chat interface for direct interaction with your agent.

<Aside type="note">
  The web chat interface is coming soon. Currently, the dashboard provides job history and settings management.
</Aside>

## Current dashboard features

### Job history

View all email interactions with your agent:
- Incoming emails and timestamps
- Agent responses
- Token usage and costs
- Error messages if any

### Settings

Configure your agent:
- **API Keys** — Your Anthropic key (encrypted)
- **Allowed Senders** — Email whitelist
- **Integrations** — Slack token (Tiny tier)

### Status

See your agent's current state:
- Recent activity
- Total usage this month
- Session information

## Planned features

### Live chat

Direct conversation with your agent in the browser:
- Send messages
- See streaming responses
- View tool calls in real time

### File browser

Browse your agent's `/data` directory:
- View MEMORY.md
- Check outbox contents
- Download files

### Activity drawer

Expand to see detailed execution:
- Tool calls in progress
- Command output
- File operations

## Alternative: Email

Until web chat launches, email is the primary interface:

1. Send to `yourname@tinyfat.com`
2. Agent processes and responds
3. View history in dashboard

Email works from any device and maintains full conversation threading.
